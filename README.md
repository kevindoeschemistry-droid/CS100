# CS 100: Introduction to Computer Science

Coursework for CS 100, using *Python Programming: An Introduction to Computer Science* (Zelle, 3rd ed.) and the [Bro Code Python course](https://www.youtube.com/watch?v=XKHEtdqhLK8).

## Layout

- `programs/`: all programming exercises, in one folder (the syllabus requires `graphics.py` to sit next to them from Chapter 4 on). Name them `chNN_peNN.py`, e.g. `ch02_pe05.py`.
- `exercises/`: written chapter exercises, one file per chapter, e.g. `ch01.md`.

## Submitting

All work is turned in through this repo. After finishing an exercise:

```bash
git add .
git commit -m "Ch 2 PE 1-5"
git push
```

Or in PyCharm: **Git → Commit** (Ctrl+K), then **Git → Push** (Ctrl+Shift+K).
